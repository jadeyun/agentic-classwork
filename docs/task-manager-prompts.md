# 任务管理应用 · 需求 Prompt 汇总

## 阶段一：项目骨架搭建

```
用 Vue 3 + Vite + Tailwind CSS 初始化一个任务管理应用项目，规划好目录结构（组件、状态管理、工具函数），暂不实现具体功能，先搭好骨架。" 执行后在浏览器里验证项目能跑起来（npm run dev 能看到空白页面/基础布局），确认无误后用 Git commit 这一轮的结果（提交信息如：init project scaffold）
```

## 阶段二：完整功能实现（CRUD + 看板 + 深色模式 + 持久化）

```
先理解现有的代码结构，实现任务的增删改查功能：标题必填、描述选填，支持三种状态（待办/进行中/完成）和三档优先级（高红、中黄、低绿）。" Agent 执行后，在浏览器里手动测试增删改查是否正常，状态和优先级显示是否正确，确认后再 commit
```

## 阶段三：UI 全面改进

```
在现有任务管理应用基础上做 UI 全面改进，具体要求：

一、新增 Dashboard 统计区域
放在页面顶部、任务列表上方，用统计卡片展示：
- 任务总数
- 待办 / 进行中 / 完成 各自数量
- 高 / 中 / 低 优先级 各自数量

二、配色方案（Vintage Americana 复古风格，支持浅色/深色模式）
用 CSS 变量或 Tailwind dark: 前缀实现，两种模式色相一致、只调明度：

浅色模式：
--bg-page: #F7F4EC;
--bg-surface: #EEE9D9;
--text-primary: #313869;
--text-secondary: #5B5F82;
--accent-primary: #313869;
--accent-secondary: #3D7187;
--border: #D8D3C2;
--priority-high: #A72E21;   /* 红 */
--priority-mid: #C98A2B;    /* 黄 */
--priority-low: #5C7A4E;    /* 绿 */

深色模式：
--bg-page: #1B1E33;
--bg-surface: #262A45;
--text-primary: #EEE9D9;
--text-secondary: #B9B6A8;
--accent-primary: #6B72A8;
--accent-secondary: #5FA3B8;
--border: #3A3F5C;
--priority-high: #D9695C;
--priority-mid: #E0AA52;
--priority-low: #7FA06B;

优先级标签保持红/黄/绿语义不变，色调向整体复古风格靠拢，不用刺眼纯色。每个优先级标签除颜色外，额外加简短文字（高/中/低）区分，不要只靠颜色区分。

三、响应式布局
看板整体容器根据浏览器窗口宽度自适应：
- 大屏幕下三列（待办/进行中/完成）等比例放大并居中，避免两侧出现大片空白
- 中等屏幕保持三列但按比例收窄
- 小屏幕（平板/手机宽度）下三列自动堆叠为单列

四、其他体验细节
- 空状态优化："拖拽卡片到此"占位提示加一个小图标，文案更友好
- 卡片增加 hover 效果（轻微阴影或边框高亮）
- 整体从深色为主的风格调整为以上配色方案为主，浅色/深色模式都要覆盖到所有组件（包括看板、卡片、按钮、弹窗）

完成后在浏览器分别验证：
1. Dashboard 统计数字是否准确
2. 浅色和深色模式下配色是否都正确应用
3. 不同窗口宽度下响应式布局是否正常
4. 优先级标签颜色+文字是否清晰可辨
```
